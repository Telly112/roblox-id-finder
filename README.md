# roblox-id-finder
## Roblox ID Finder
================

A simple and fast web tool built with pure HTML/JavaScript to search and retrieve details for any Roblox ID.

Features
--------
* User Profiles (Avatars & Profile Links)
* Catalog Assets
* Groups
* Badges
* Game Passes
* Places / Experiences

How to Use
----------
Simply open the index.html file in any web browser. Enter the desired Roblox ID into the search bar and click Search.

Built With
----------
* HTML5 / CSS3
* JavaScript (ES6+ / Fetch API)
* Public Roblox APIs
* CORS Proxies (allorigins / corsproxy)
